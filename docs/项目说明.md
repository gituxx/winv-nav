## 工作原理

```mermaid
flowchart LR
  你["访客"] --> 导航["nav.winv.cc（一个网页文件，放在 Cloudflare 上）"]
  导航 -->|"点击"| 站["9 个小站，各自独立运行"]
```

导航页只负责“列出链接”，不存任何数据。每个小站是独立的项目，导航页坏了不影响它们，反过来也一样。

另外，三个影视站里用户改的设置只保存在**他自己的浏览器里**，不会影响别人；清理浏览器缓存后会恢复默认。

## 日常维护：什么时候需要你出手

- 要增删、修改导航里的站点：告诉 AI 就行，AI 可以直接改。
- 某个 `xxx.winv.cc` 打不开：告诉 AI 恢复，一般就是一条命令的事。
- 域名到期（2032 年）：需要你本人登录注册商续费。
- 更换 Key：需要你本人在 Cloudflare / GitHub 网站上操作，然后把新 Key 发给 AI。

## 风险与限制

- **内容合规**：导航里有多个影视聚合站和 TVBox 订阅源，内容来自第三方，可能涉及版权问题。公开分享给很多人用，有被投诉的风险。另外，Cloudflare 的服务条款不允许用它的服务分发侵权内容。
- **免费额度**：Workers 免费版每天 10 万次请求，导航页的访问量远远用不到。
- **开源许可**：导航页是从零写的，没有用第三方代码；图标是手画的线条风格，没有直接复制任何图标库。被收录的各个小站有各自的许可证，与本项目无关。
- **单点风险**：所有东西都在同一个 Cloudflare 账号下，账号出问题会全部受影响。
